# 📐 Digital Calculator

A professional, responsive, and feature-rich **2D & 3D Geometric Shapes Calculator**, **Scientific Calculator**, and **Unit Converter** built with **HTML, CSS, and Vanilla JavaScript**. 

This project works as a **Progressive Web App (PWA)**, meaning it can be installed on mobile devices and used offline without an internet connection!

## 🚀 Live Demo
👉 **[Click here to view the Live Calculator](https://mrcomputer809prog.github.io/DIGITAL-CALCULATOR-/calculator.app/)**

## ✨ Amazing Features

- **📐 16 Shapes Supported:** 
  - **2D Shapes:** Rectangle, Square, Triangle, Circle, Parallelogram, Rhombus, Trapezoid, Pentagon, Hexagon, Ellipse.
  - **3D Shapes:** Cube, Cuboid, Sphere, Cylinder, Cone, Pyramid, Hemisphere, Torus.
- **🧮 Scientific Calculator:** In-built scientific calculator for advanced math (sin, cos, tan, log, factorial, etc.).
- **📏 Unit Converter:** Convert Length, Weight, Temperature, Data Storage, and Time.
- **⚖️ Ratio Calculator:** Find the simplest ratio of multiple numbers instantly.
- **📊 Percentage Calculator:** Easily calculate percentages.
- **📈 Logarithm Calculator:** Calculate Log base 10, Natural Log, Log base 2, and Custom Base.
- **🌍 Live Currency Converter:** Real-time exchange rates for USD, PKR, EUR, GBP, INR, SAR, and AED.
- **🔊 Voice & Sound:** The calculator speaks the result out loud and features interactive click sounds!
- **🌙 Dark Mode / Light Mode:** Smooth theme toggling with memory (saves your preference).
- **📜 Calculation History:** Automatically saves your last 20 calculations.
- **🖨️ Print / Save as PDF:** Easily print your calculations or save them as a PDF.
- **📱 Installable (PWA):** Can be installed on Android, iOS, and Windows as a native-like app.
- **🔒 100% Secure:** Built with HTTPS and Content Security Policy (CSP).

## 🛠️ Technologies Used
- **HTML5** (Semantic structure, PWA Manifest)
- **CSS3** (Variables, Flexbox, Grid, Glassmorphism, Animations, Responsive Design)
- **JavaScript (ES6)** (DOM Manipulation, Math, LocalStorage, Web Speech API, Service Workers)
